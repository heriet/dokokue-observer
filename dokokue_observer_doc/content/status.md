# ステータス

## ステータスとは

- 画面に表示されているキャラクタ情報ではステータスと装備を計算した値となる。計算元となる値をここではステータスと呼ぶ
- キャラクタの初期値は最大HP100、命中50、回避50、魔法0、敏捷20
- PCリストで表示されるSkillはステータスの合算。`Skill = 命中 + 回避 + 魔法 + 敏捷`。そのためSkillの初期値は120

## ステータスの上昇・下降

- ステータスは対応する実を使用することでステータスアップまたはダウンできる
- ステータスアップの実はSkill値が高くなるにつれ少しずつ効果が減衰する
  - Skillが高くなって 0.0 上昇しました！と表示されるようになっても、小数点以下で増加している
- ステータスダウンの実はステータスに寄らず整数値で1or2減少。ただし現ステータスが0以下の時は無効
- ステータス1.0未満の時にステータスダウンの実を食べるとマイナス値にできる
    - 0以下でステータスダウンはできないため、実質-1.9ぐらいが限界
- Skillは最大HPを超えて上昇できない。最大HPに達したとき、ステータスアップの実を食べてもステータス上昇値が0になる
- 初期魔術の実は前世では魔法値が強制で3～12のどれかになる効果だったが、今世は3～12上がる効果（たぶん上限は12）になっている様子
    - つまり現魔法値が20のとき、初期魔術の実を食べても魔法値を3～12に戻すことはできない。0上昇の効果になる

## 命中

- 攻撃の命中確率に影響するステータス
- 命中ステータスは `決定打` の発生確率にも影響する
    - 昔の仕様では、決定打は防御無視かつ確率でダメージが増幅する攻撃
    - 昔の仕様では、決定打の発生確率は `命中/1000 %`
    - おそらく命中が1未満だと決定打が発生しない
- `キャラクタ情報の命中 = (命中 + 敏捷/2) + 装備の命中 × (命中 + 敏捷/2)/100`

## 回避

- 攻撃の回避確率に影響するステータス
- 回避ステータスは `巧みなガード` の発生確率にも影響する
    - 昔の仕様では、巧みなガードの発生確率は `回避/1000 %`
    - おそらく回避が1未満だと巧みなガードが発生しない
- `キャラクタ情報の回避 = (回避 + 敏捷/2) + 装備の回避 × (命中 + 敏捷/2)/100`

## 魔法

- 魔法の発動率に影響するステータス。キャラクタ情報の魔法がそのまま魔法の発動率となる
    - つまり最終的に装備込みで100以上に調整したいが、100を超過しても強くはならない
- 魔法ステータスが0以下だと、装備で魔法値を底上げしても魔法が発動しない
    - 0以下でなければよいので、魔法ステータスを低く調整するなら 0.1 ぐらいに調整するのも手
- `キャラクタ情報の魔法 = 魔法 + 装備の魔法`
- ビルドにもよるが、強い装備が整ってくると魔法は装備で補えることが多いので、あまり上げすぎる必要はない

## 敏捷

- 逃走率やマジックアイテムの発現率に影響するステータス
- 隠しステータスであり、キャラクタ情報には明示されない
- 敏捷値の半分が最終的な命中と回避の計算に使われるが、決定打や巧みなガードの確率には影響しない
- 逃走率は敏捷が高いほど確率が高くなるが、今はどんなに高くても100%にはならない模様
    - 遭遇仕様の変更前は `逃走率 = 敏捷値` で、敏捷100以上なら確定逃走できたが、仕様変更によりこの計算は変わっている様子
    - 現状はおそらく敵によって逃走率が変わる。雑魚は逃げやすいが強敵は逃げにくい
        - 特にわかりやすいのが、ミスリルスライムからは妙に逃げにくかったりする 
    - 攻撃の命中・回避のように、逃走もプレイヤー側の敏捷と敵の敏捷ステータスで対抗するようになった？
